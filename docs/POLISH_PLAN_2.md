# 墨枢 · 第二轮 30 轮精细打磨计划（R51–R80）

对标对象：Day One（记忆重现、模板、导出）、Bear（标签体系、Markdown）、Flomo（快速记录、热力图）、
Obsidian（双向链接、反链）。审计方式是先按功能面 grep 现有代码，只写确实缺失的轮次。

约定与前 50 轮相同：不写入任何 API Key；默认模型用稳定别名 `deepseek-flash`；
改实体必须升 `AppDatabase.version` 并补 `MIGRATION_n_m`；每个批次跑 `assembleDebug testDebugUnitTest`。

## 一、记录与组织

- **R51 标签管理**：`tagsJson` 目前只能由 AI 写入，用户无法重命名/合并/删除标签。新增「标签」管理页：
  列出全部标签及条目数，支持重命名、合并到另一标签、删除（仅从条目上摘掉，不删条目）。
- **R52 往年今日**：「今天」页新增「往年今日」卡片，展示去年/前年同一天（±1 天）的记录；无内容时不显示。
- **R53 回收站**：删除目前直接消失。新增软删除（`EntryEntity.deletedAt`）与回收站页，
  保留 30 天，支持恢复与彻底删除；列表与搜索默认排除已删除项。
- **R54 星标条目**：`isPinned` 是「置顶」，缺少「收藏但不置顶」。新增 `isStarred` 与筛选，详情页可切换。
- **R55 模板**：新增记录模板（晨间日记 / 复盘 / 读书笔记 / 空白），在输入框上方可选，
  模板内容预填进草稿，模板存本地设置。
- **R56 双向链接**：正文里写 `[[标题]]` 时渲染成可点链接，跳转到同名条目；
  详情页底部显示「被引用」反链列表。解析在内存完成，不改表结构。

## 二、阅读与检索

- **R57 正文可调字号**：详情页正文支持字号三档（小/标准/大），设置持久化，长文阅读更舒适。
- **R58 条目内搜索并定位**：详情页支持搜索当前正文，命中处高亮并逐条跳转。
- **R59 详情页左右滑动切换**：在当前筛选结果内左右滑动切到上一条/下一条，避免反复返回列表。
- **R60 最近搜索词**：搜索框聚焦时展示最近 8 条搜索词，可单条删除或全部清空。
- **R61 全库日历视图**：月历标出有记录的日子（按条数深浅着色），点击某天跳到当天记录。
- **R62 全年热力图**：回顾页把「本月热力图」扩展为「近一年」，点击格子跳到对应月份。

## 三、统计与洞察

- **R63 写作统计**：新增写作统计卡：累计字数、平均每条字数、最长连续天数、最常写的时间段。
- **R64 情绪与标签关联**：回顾页显示「最常与某情绪共现的标签」，帮助发现自己的模式。
- **R65 字数与阅读时长**：详情页显示本条字数；列表卡片可选显示字数。

## 四、导出与分享

- **R66 导出单条为 Markdown 文件**：详情页可把当前条导出成 `.md` 文件（`ACTION_CREATE_DOCUMENT`）。
- **R67 批量导出为 Markdown**：记忆页多选后导出所选条目为一个 Markdown 文件。
- **R68 导出带图片**：导出 Markdown 时可选打包图片（zip），图片按条目分目录。

## 五、可靠性与隐私

- **R69 应用锁**：支持 PIN 或生物识别解锁，开启后进入应用需验证；密钥与设置不进备份。
- **R70 自动备份**：按天/周自动导出备份到指定目录（SAF 持久授权），失败有通知。
- **R71 提醒通知的直接操作**：待办提醒通知增加「完成」与「推迟一天」按钮，不必进应用。
- **R72 桌面快捷方式**：长按图标可「写一条」「搜一搜」「看往年今日」。
- **R73 数据完整性自检**：启动时检查孤儿附件、无效分类、悬空待办来源，并在设置页提供一键修复。

## 六、打磨

- **R74 图片查看器手势**：大图支持双指缩放与拖动，双击放大/还原。
- **R75 深色跟随时间**：外观增加「日出日落自动切换」（按本地时间粗略计算）。
- **R76 空状态与引导**：各页空状态给出下一步动作按钮，而不是只有一句说明。
- **R77 无障碍完善**：补齐卡片、图表、图标的 TalkBack 描述与状态播报。
- **R78 性能：列表与图片**：记忆页长列表的图片解码与滚动优化，避免掉帧。
- **R79 键盘与外接设备**：外接键盘支持 Ctrl+F 搜索、Ctrl+N 新建、Esc 返回。
- **R80 收尾清理**：重复实现合并、无引用符号删除、文案一致性复查。

## 落地状态

已实现：

- **R51 标签管理**：`ui/tags/`（列表 + 重命名 + 合并 + 移除）。三种操作都只改 `tagsJson`，
  确认文案明确写出「不会删除记录」。设置页新增入口。
- **R52 往年今日**：`JournalRepository.onThisDay()` 逐年做区间扫描（2 月 29 日在平年会抛异常，按跳过处理）；
  「今天」页在「今天的记忆」之前显示最多 3 条，无内容时整块不出现。
- **R53 回收站**：`EntryEntity.deletedAt` 软删除 + schema v5 与 `MIGRATION_4_5`；
  `EntryDao` 所有列表/搜索/统计查询都补了 `deletedAt = 0`；`ui/trash/` 支持恢复与彻底删除；
  启动时清理超过 30 天的条目（含图片文件）。删除的撤销路径也改成「从回收站恢复」，不再依赖 8 秒计时器。
- **R54 收藏**：`EntryEntity.isStarred`；记忆页筛选块、卡片长按菜单、详情页顶栏三处可切换。
- **R55 模板**：`ui/components/EntryTemplates.kt`（空白/晨间/复盘/读书/灵感）；
  只在草稿为空时显示，避免误触覆盖已写好的正文。
- **R56 双向链接**：`[[标题]]` 在详情页渲染成可点链接（`LinkAnnotation.Clickable`），
  下方显示「引用了 / 被引用」两组；找不到同名条目时给明确提示而不是静默失效。
- **R57 正文字号**：详情页正文三档字号，按条目记忆。
- **R63 写作统计**：累计条数/字数/均长/最长连续天数/最常写字时段，回顾页新增卡片。
- **R66 导出单条 Markdown**：详情页溢出菜单导出 `.md`；顶栏图标从 4 个收到 2 个 + 溢出菜单。
- **R72 桌面快捷方式**：「写一条」「搜一搜」；`res/xml/shortcuts.xml` + `moshu://search` 深链。
- **R73 数据完整性自检**：`integrityReport()` / `repairIntegrity()`，设置页可自检与修复
  （孤儿图片、悬空来源、非法分类），修复只做无争议清理。
